
# UniVerse — GPA Simulator

An interactive web application that helps university students calculate their GPA and simulate future academic results.

## Features

- Calculate a weighted GPA
- Convert letter grades into grade points
- Simulate future cumulative GPA
- Compare academic scenarios
- Interactive dashboard

## Technologies

- Python
- Streamlit
- Git & GitHub

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Disclaimer

GPA calculations are estimates. Grade scales and academic regulations may vary between universities.
